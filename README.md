# 📝 Simple Task Management System

A full-stack web application for managing tasks with priorities, user authentication, and a clean UI.  
Built as part of the **Magnet Brains Full Stack Developer Assignment Round**.

---

## 🚀 Features

- **Task Creation** – Add tasks with a title, description, due date, and priority.
- **Task Lists with Pagination** – View tasks with AJAX-powered pagination for smooth loading.
- **Task Details** – Click on any task to view its full details.
- **Task Editing** – Update task title, description, due date, and priority.
- **Task Deletion** – Delete tasks with a confirmation dialog to prevent accidental removal.
- **Status Updates** – Mark tasks as “Pending” or “Completed” or change their status anytime.
- **User Authentication** – Secure login/logout. Only authorised users can create, edit, delete, or assign tasks.
- **User Management** – Admin can add/remove users and assign tasks.
- **Priority Management** – Move tasks between priority lists (e.g. High, Medium, Low).
- **Visual Cues** – Each priority list is colour-coded for quick identification.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (AJAX), React, Tailwind
- **Backend**: Node.js + Express
